# 🅿️ みんなの駐車場マップ

周辺の駐車場を地図に📍で表示し、**誰でも匿名で登録・共有**できるコミュニティ型の駐車場マップです。
料金は**看板の写真を根拠として添付**し、**更新日・確認日**を明示することで、古い情報やガセを見分けられます。
「駐車場を探すのがめんどい」「最安値の駐車場を見つけたい」を解決することが目的です。

**PHP + MySQL** で動作し、コアサーバー等の共有レンタルサーバーにアップロードするだけで運用できます。

## 主な機能

- 🗺️ **地図表示**：Leaflet + OpenStreetMap（APIキー不要・リポジトリに同梱）。ピンに概算料金を表示し、料金帯で色分け（安=緑 / 中=橙 / 高=赤 / 不明=灰）。
- 📍 **現在地から初期表示**：起動時に位置情報を取得し、その付近の駐車場を**「近い順」で初期表示**。地図を動かすとその範囲の駐車場を自動で再取得。
- ➕ **匿名で登録**：地図をタップして位置を指定 → 名前・時間料金・最大料金・料金メモ・料金看板の写真を登録。ログイン不要。
  - 📷 **写真は必須**：料金看板の写真が無い登録は受け付けません（情報の信頼性を担保するため）。
  - 🏠 **住所・名称を自動入力**：地図タップ位置から、無料の OpenStreetMap（Nominatim）逆ジオコーディングで住所・施設名を自動取得してフォームに補完。あくまで候補なので、登録前に本人が確認・修正できます（APIキー・費用なし。取得失敗時は手入力）。
- 💰 **最安ソート**：「近い順 / 概算が安い順 / 時間料金順 / 最大料金順 / 新着順」。駐車時間（30分〜1日）を選ぶと概算料金を再計算。
- ✅ **信頼性の担保（ガセ・古い情報対策）**
  - 料金看板の**写真を一次情報**として添付（未添付は「📷写真なし」バッジ）。
  - **更新日/最終確認日**を相対表示。古い情報は⚠️バッジ。
  - 「✅情報は正しい」「⚠️違う/古い」ボタン（匿名トークンで**1人1票**）。報告が多い駐車場は赤ピン＋「要確認」。
  - **報告がたまると自動で非表示**：報告が5件以上たまり、かつ確認数を上回った駐車場は自動的に地図・一覧から消えます（管理者の手作業不要）。確認が多い＝みんなに支持された情報は守られ、誤爆でもDBには残るため復元可能。
- 🤝 **みんなの確認で信頼度が上がる**（中央管理者なしの合意形成）：複数人が「✅正しい」を押すほど、その駐車場の信頼度ランクが上がります（未確認 → 情報あり → ✅みんなが確認(3人) → 🏅認定(10人)）。ポップアップに「あと N 人で認定」と表示。
- 🕒 **3か月ごとの再確認サイクル**：最終確認（または更新）から**約3か月**が過ぎると、たとえ「認定」済みでも「🕒 要更新」に切り替わり、再確認をうながします。誰かが「✅正しい」を押すと最新に戻ります（＝情報が古いまま放置されない）。要更新の情報を再確認すると**ボーナスポイント**＋「🕒 鮮度キーパー」バッジがもらえ、鮮度維持が報われる仕組みです。
- 🏅 **貢献ランク＆バッジ**：登録・写真添付・確認/報告・「自分の情報が他人に確認された」数に応じてポイントが貯まり、🥉ブロンズ→🥈シルバー→🥇ゴールド→💎プラチナへ。ヘッダーのチップから貢献パネル（進捗・バッジ）を確認できます。※匿名トークン（端末単位）で集計。
- 🔰 **初期データ**：OpenStreetMap 由来の実在駐車場（位置・名称）にサンプル料金とプレースホルダ看板画像を付けて投入できます。すべて「サンプル・未確認」と明示され、利用者が確認・修正して育てられます。

## 技術スタック

| 層 | 採用技術 |
|---|---|
| 地図 | Leaflet 1.9 + OpenStreetMap タイル（`vendor/leaflet/` に同梱・CDN非依存） |
| サーバ | PHP（フレームワークなし・PDO） |
| DB | MySQL（本番）／ SQLite（ローカル検証）※`lib/db.php` がドライバ両対応 |
| 画像 | クライアント側とサーバー側（GD）の二重で長辺1280px・JPEG圧縮してから保存（容量節約） |
| フロント | バニラ JS + HTML + CSS（ビルド不要・モバイルファースト） |

## ディレクトリ構成

```
index.html / styles.css / app.js   フロント（そのまま public に置く）
vendor/leaflet/                     Leaflet 本体（同梱）
api/index.php                       API のフロントコントローラ
lib/                                db.php / estimate.php / helpers.php / config.php
uploads/                            投稿写真の保存先（要書き込み権限）
tools/seed.php                      初期データ投入スクリプト
seed/seed.json                      初期データ（OSM実在駐車場＋サンプル料金）
schema.sql                          MySQL スキーマ（phpMyAdmin 取り込み用）
router.php                          ローカル検証用（php -S）※本番では未使用
```

## コアサーバー（共有レンタルサーバー）への設置手順

1. 管理パネルで **MySQL データベースを作成**（DB名・ユーザー・パスワード・ホストを控える）。
2. `lib/config.sample.php` を `lib/config.php` にコピーし、`driver => 'mysql'` と接続情報を記入。
3. このリポジトリ一式を **`public_html`（公開ディレクトリ）にアップロード**。
4. `uploads/` を**書き込み可能**に（パーミッション 755〜775）。
5. サイトにアクセス → 初回アクセスで**テーブルが自動作成**されます（`schema.sql` を phpMyAdmin から取り込んでもOK）。
6. 初期データを入れる場合は SSH で `php tools/seed.php` を実行（東京駅周辺のサンプルが入ります）。

> `.htaccess` により `/api/*` は `api/index.php` に集約され、`lib/`（DB認証情報）は外部アクセス拒否、`uploads/` は PHP 実行禁止に設定済みです。

## ローカルで動かす（検証用・MySQL不要）

```bash
# 1) sqlite 設定を用意
cp lib/config.sample.php lib/config.php
#    lib/config.php を driver => 'sqlite' に（既定のサンプルは sqlite 例つき）

# 2) 起動（PHP のビルトインサーバー + ルーター）
php -S localhost:8000 router.php

# 3) 初期データ投入（任意）
php tools/seed.php

# → http://localhost:8000 を開く
```

## API

| メソッド | パス | 説明 |
|---|---|---|
| `GET` | `/api/lots?sort=distance\|estimate\|hourly\|max\|updated&hours=1&bbox=minLng,minLat,maxLng,maxLat` | 一覧（並び替え・概算時間・範囲絞り込み） |
| `GET` | `/api/lots/{id}` | 詳細 |
| `POST` | `/api/lots` | 新規登録（multipart: フィールド + `photo`） |
| `POST` | `/api/lots/{id}` | 編集（multipart。※PHP は PUT+multipart で `$_FILES` が空になるため POST に統一） |
| `POST` | `/api/lots/{id}/confirm` | 「情報は正しい」確認（JSON body: `client_token`）。応答に投票者の最新貢献度 `me` を含む |
| `POST` | `/api/lots/{id}/report` | 「違う/古い」報告（JSON body: `client_token`, `comment?`） |
| `GET` | `/api/users/me?token=...` | 自分の貢献ランク・ポイント・バッジ・統計 |

各駐車場には信頼度ランク（`trust`）が付与され、確認数に応じて「未確認→情報あり→みんなが確認→認定」と上がります。

※「近い順（distance）」は現在地が必要なためクライアント側で距離計算・ソートします。

## 初期データについて（権利）

初期データの**位置・名称は OpenStreetMap 由来**（ODbL ライセンス・再利用可）です。料金はサンプル値、
看板画像はアプリが生成したプレースホルダで、すべて `source='osm'` として「🔰 サンプル・未確認」と明示されます。
Google マップ等の写真・データは権利上取り込んでいません。別エリアの初期データは Overpass API から取得して
`seed/seed.json` を差し替えれば再生成できます。

## 管理画面（削除・非表示）

- `lib/config.php` に `admin_password`（十分に長い文字列）を設定します。
- `https://あなたのサイト/admin.html` を開き、パスワードでログイン。
- 投稿一覧から **削除／非表示／復活** をワンクリックで操作できます（不適切な写真・スパムの対処用）。

## ログイン（アカウント）

- **ニックネーム＋パスワード**でアカウント登録・ログイン（パスワードは `password_hash` でハッシュ保存）。
- **閲覧は誰でも自由**。**登録・編集・確認・報告はログイン必須**。
- 投稿者・投票の識別は**サーバーのセッション（＝アカウント）**から取得するため、クライアント値の偽造は無効（**1アカウント1票**が保証され、投票操作の根本対策）。
- 貢献ポイント/ランク/バッジはアカウントに紐づきます。

## 不適切な写真・投稿への対処

- ポップアップの **「🚩 不適切」** から通報でき、**10アカウントの通報で自動非表示**（ログイン必須なので通報が信頼できる前提。誤通報・少人数での巻き添えを防ぐため10件に設定）。
- 通常の「⚠️違う/古い」通報も、5件以上かつ確認数を上回ると自動非表示。
- 残ったものは管理画面（`admin.html`）から削除できます。

## スパム・スクリプト対策

- **レート制限**：登録5件/分・30件/時、編集10件/分、確認/報告20件/分（IP単位）。超過は 429。
- **同一サイトのみ受付**：書き込みAPIは Origin/Referer を検査し、素のスクリプト（curl 等）を拒否。
- **ハニーポット**：登録フォームの隠しフィールドに入力がある送信を bot として無視。
- ※ ログイン/CAPTCHA なしのため完全な bot 遮断ではありません（casual なスクリプトを弾く多層防御）。本格運用ではアカウント制の導入が有効です。

## 本番運用のメモ

- `data/`（sqlite 使用時）と `uploads/` は**永続領域**に置いてください。
- **自動お掃除（cron 推奨）**：`php tools/cleanup.php` を1日1回 cron 登録しておくと、
  ①非表示のまま30日たった駐車場を写真ごと完全削除、②どの駐車場からも参照されていない
  孤立画像を削除、③30日以上使われていない OSM 駐車場キャッシュ（cache/）を削除——を
  自動で行い、ストレージが管理者の手作業なしで片付きます。
  （OSM駐車場キャッシュの有効期間も30日です。位置はほぼ変わらないため長めに設定）
- 荒らし対策は confirm/report ＋ 上記の自動非表示。誤爆は DB に残るので phpMyAdmin で `hidden=0` に戻せます。
- `lib/config.php`（DB認証情報）は Git 管理外です。
