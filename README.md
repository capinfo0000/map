# 🅿️ みんなの駐車場マップ

周辺の駐車場を地図に📍で表示し、**誰でも匿名で登録・共有**できるコミュニティ型の駐車場マップです。
料金は**看板の写真を根拠として添付**し、**更新日・確認日**を明示することで、古い情報やガセを見分けられます。
「駐車場を探すのがめんどい」「最安値の駐車場を見つけたい」を解決することが目的です。

## 主な機能

- 🗺️ **地図表示**：Leaflet + OpenStreetMap（APIキー不要）。ピンに概算料金を表示し、料金帯で色分け（安い=緑 / 中=橙 / 高=赤 / 不明=灰）。
- 📍 **現在地取得**：ブラウザの位置情報で周辺へジャンプ。各駐車場までの距離も表示。
- ➕ **匿名で登録**：地図をタップして位置を指定 → 名前・時間料金・最大料金・料金メモ・**料金看板の写真**を登録。ログイン不要。
- 💰 **最安ソート**：「概算が安い順 / 時間料金順 / 最大料金順 / 新しい順」で並び替え。
- ⏱️ **駐車時間で概算**：30分 / 1時間 / 3時間 / 1日を選ぶと、各駐車場の概算料金を再計算（`概算 = min(時間料金 × 時間, 最大料金)`）。用途に合った最安がわかる。
- ✅ **信頼性の担保（ガセ・古い情報対策）**
  - 料金看板の**写真を一次情報**として添付（未添付は「📷写真なし」バッジで注意喚起）。
  - **更新日/最終確認日**を相対表示（例「3日前に更新」）。古い情報は⚠️バッジ。
  - 「✅情報は正しい」ボタンで確認 → 最終確認日を更新し、みんなで鮮度を維持。
  - 「⚠️違う/古い」ボタンで報告 → 報告が多い駐車場は赤ピン＋「要確認」表示。
  - 確認・報告は**匿名トークンで1人1票**（localStorage）。

## 技術スタック

| 層 | 採用技術 |
|---|---|
| 地図 | Leaflet 1.9 + OpenStreetMap タイル |
| サーバ | Node.js + Express |
| DB | SQLite（better-sqlite3、単一ファイル） |
| 画像 | multer でアップロード。クライアント側で長辺1280px / JPEG圧縮してから送信 |
| フロント | バニラ JS + HTML + CSS（ビルド不要・モバイルファースト） |

## セットアップ・起動

```bash
npm install
npm start          # http://localhost:3000
# 開発時（ファイル変更で自動再起動）
npm run dev
```

環境変数（任意）:

| 変数 | 既定値 | 説明 |
|---|---|---|
| `PORT` | `3000` | 待ち受けポート |
| `DATA_DIR` | `./data` | SQLite の保存先 |
| `UPLOAD_DIR` | `./uploads` | アップロード画像の保存先 |

## API

| メソッド | パス | 説明 |
|---|---|---|
| `GET` | `/api/lots?sort=estimate\|hourly\|max\|updated&hours=1&bbox=minLng,minLat,maxLng,maxLat` | 駐車場一覧（並び替え・概算時間・表示範囲絞り込み） |
| `GET` | `/api/lots/:id` | 駐車場詳細 |
| `POST` | `/api/lots` | 新規登録（multipart: フィールド + `photo`） |
| `PUT` | `/api/lots/:id` | 編集（写真の差し替え可） |
| `POST` | `/api/lots/:id/confirm` | 「情報は正しい」確認（body: `client_token`） |
| `POST` | `/api/lots/:id/report` | 「違う/古い」報告（body: `client_token`, `comment?`） |

## データ構造

- `lots`：駐車場（名前・座標・時間料金・最大料金・料金メモ・写真・更新日・確認/報告カウント 等）
- `reports`：確認/報告ログ（`(lot_id, client_token, kind)` を UNIQUE にして1人1票）

料金の複雑さ（20分課金・夜間最大など）は、比較可能性を優先して **時間料金/最大料金の2軸に正規化**し、詳細は料金メモ＋写真で担保しています（写真が一次情報、数値は目安）。

## 本番公開に向けたメモ

- SQLite ファイル（`data/`）とアップロード画像（`uploads/`）は**永続ボリューム**に置いてください。エフェメラルな環境では再起動で消えます。
- 画像保存先は将来 S3 互換ストレージへ移行しやすいよう `UPLOAD_DIR` で切り出しています。
- 匿名投稿のため、荒らしが問題化した場合は投稿レート制限・簡易認証・モデレーションの追加を検討してください（DB のクエリ層 `db.js` を薄く保っているので拡張しやすい構成です）。
